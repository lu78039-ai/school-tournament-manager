# 學校競賽抽籤與計分

適用於班級及個人競賽的繁體中文網頁工具，支援單敗淘汰、雙敗淘汰、兩分區比賽、隨機輪空，以及 1～4 個場地。

## 開始使用

直接用 Chrome 或 Edge 開啟 `index.html` 即可進行抽籤、記分與本機保存。設定完成後，點選賽程上的場次開啟記分板。

提供一般比分、各局比分與三戰兩勝模式，可記錄裁判裁定、開始及結束時間。平手比分可先保存，確認勝隊後才晉級。

## 多場地連線

主電腦需安裝 Python 3 與 Node.js，並讓 `python`、`node` 可以執行。在 Windows 雙擊 `啟動對戰抽籤表.cmd`，或執行：

```sh
python server.py
```

主電腦開啟 `http://127.0.0.1:8765/`，完成抽籤後啟用連線同步。各場地裝置連上相同區域網路或手機基地台，使用畫面提供的場地地址與連線碼。

斷線期間可在已開啟的場地頁面繼續記分，恢復連線後同步，也可匯出場地紀錄交由主電腦整合。離線期間請保持頁面開啟並匯出備份。

## 保存與備份

資料保存在使用裝置的瀏覽器，提供 JSON 備份、可攜網頁、場地紀錄及賽程圖下載。`.sync` 包含本機同步資料與連線碼，不列入版本管理。

GitHub Pages 可提供靜態網頁使用；多裝置即時整合需要另外執行本機同步伺服器。

完整操作請參閱 [使用說明](使用說明.md)。
